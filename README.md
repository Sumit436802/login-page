# Login Page

A clean, responsive login page built with HTML, CSS and a little JavaScript. I built it step by step as a practice project to learn front-end web development.

## Features

- Centred login card with rounded corners and a soft shadow
- Email and password fields with built-in validation
- Show/Hide password button
- "Forgot password?" and "Create an account" links
- Hover and focus effects on the inputs and button
- Responsive layout that works on phones and desktops

## Built with

- HTML5
- CSS3 (flexbox/grid, media queries)
- JavaScript (for the show/hide password button)

## Project structure

```
login-page/
├── index.html    # page structure and form
├── style.css     # all the styling
└── README.md
```

## How to run

1. Download or clone this repository.
2. Open `index.html` in your browser.

No installation is needed.

## What I learned

- Structuring a form with labels, inputs and buttons
- Centring content with CSS grid
- Styling focus and hover states
- Making a layout responsive with media queries
- Using JavaScript to change an input's type
